# 📍 MySafe — GPS Tracking par SMS de données invisible

Application Android discrète SANS internet, par SMS de données uniquement.
- ❌ Aucun message visible dans la messagerie
- 📍 !!POSITION → Position immédiate
- ▶️ !!DEMARRER → Suivi continu (10m / 1min30)
- ⏹️ !!STOP → Arrêt
- 🗺️ Carte OSMdroid hors-ligne
- 🔄 Redémarrage automatique au boot

⚠️ **Usage légal uniquement** : Sur votre propre appareil ou avec consentement explicite.
